Vector Spaces, Basis, Rank & Linear Mappings

Which vectors can you build from a few "ingredient" vectors? The answer tells you how much real information a dataset holds.

Lesson overview

In Module 0 you learned to scale and add vectors. This module asks: if you're only allowed a few starting vectors, what can you build? That question leads to four ideas (span, independence, basis, rank) that tell you whether your data has redundant columns, which matters every time you fit a model.

By the end of this module you will be able to

  • Decide whether a vector can be built from other vectors, and find the recipe.
  • Tell whether a set of vectors is independent or has a redundant member.
  • Explain what a basis is and find coordinates in a new basis.
  • Compute the rank of a small matrix and say what it means for data.
  • Find the kernel: the inputs a matrix sends to zero.

Linear combinations and span: what can you build?

≈ 25 min

A linear combination of vectors $\mathbf{u}$ and $\mathbf{v}$ is $a\mathbf{u} + b\mathbf{v}$ for some numbers $a$ and $b$. The span is everything you can make this way, using every possible $a$ and $b$.

Worked example · can we build $(7, 4)$ from $\mathbf{u} = (1, 2)$ and $\mathbf{v} = (3, 1)$?
  1. $a(1, 2) + b(3, 1) = (7, 4)$
    We're looking for the amounts $a$ and $b$.
  2. $a + 3b = 7, \qquad 2a + b = 4$
    Match the first entries, then the second entries. It's a Module 1 system!
  3. $b = 4 - 2a \;\Rightarrow\; a + 3(4 - 2a) = 7 \;\Rightarrow\; -5a = -5 \;\Rightarrow\; a = 1$
    Solve the second equation for $b$ and substitute.
  4. $b = 4 - 2(1) = 2$
    Back-substitute.
  5. Check: $1(1, 2) + 2(3, 1) = (1 + 6,\; 2 + 2) = (7, 4)$ ✓
Recipe: $(7, 4) = 1\cdot\mathbf{u} + 2\cdot\mathbf{v}$

In fact $\mathbf{u}$ and $\mathbf{v}$ can build every point in the plane, because they point in genuinely different directions. Their span is the whole 2D plane, written $\mathbb{R}^2$.

In real life

Your screen makes every color by mixing just three lights: red, green, and blue. Every color is a linear combination $r\cdot\text{Red} + g\cdot\text{Green} + b\cdot\text{Blue}$, so the span of those three is every color the screen can show. A printer with only red and yellow ink can make oranges, but never blue: blue isn't in their span.

Span = everything you can mix from your ingredients.
Try it yourself (click to reveal the answer)
Write $(5, 5)$ as a combination of $(1, 2)$ and $(3, 1)$.
$a + 3b = 5$ and $2a + b = 5$. From the second, $b = 5 - 2a$; then $a + 15 - 6a = 5$, so $a = 2$ and $b = 1$. Check: $2(1,2) + 1(3,1) = (5, 5)$ ✓.

Linear independence: is anyone redundant?

≈ 20 min

Vectors are linearly independent if none of them can be built from the others. If one can, it's dependent: it adds nothing new.

Worked example · $(1, 2)$ and $(2, 4)$
  1. $(2, 4) = 2 \times (1, 2)$
    The second vector is just the first one stretched.
  2. $a(1, 2) + b(2, 4) = (a + 2b)(1, 2)$
    Any combination is still a multiple of $(1, 2)$.
Dependent. Their span is only a line through the origin, not the whole plane. You can never build $(1, 0)$ from them.

Quick test for two vectors in 2D: put them as columns of a matrix and compute the determinant. $\det\begin{bmatrix}1&2\\2&4\end{bmatrix} = 4 - 4 = 0$ means dependent; $\det\begin{bmatrix}1&3\\2&1\end{bmatrix} = 1 - 6 = -5 \ne 0$ means independent.

In real life

A weather dataset with both "temperature in °C" and "temperature in °F" has a redundant column: $F = 1.8C + 32$, so once you know one you know the other. A survey that asks "How old are you?" and "What year were you born?" has the same problem. Redundant columns confuse regression models (Module 1's $X^\top X$ can't be inverted), so data scientists check for them first.

Dependent = "I could have told you that already."

Basis: the smallest complete set of ingredients

≈ 25 min

A basis is a set of vectors that (1) spans the whole space and (2) is independent. It's a minimal set that can build everything, with no waste. The number of vectors in a basis is the dimension: a plane needs 2, 3D space needs 3.

The usual basis for the plane is $\mathbf{e}_1 = (1, 0)$ and $\mathbf{e}_2 = (0, 1)$: "right one" and "up one". When you write $(7, 4)$, you secretly mean $7\mathbf{e}_1 + 4\mathbf{e}_2$.

Worked example · the same point in a different basis

Use the basis $\mathbf{u} = (1, 2)$, $\mathbf{v} = (3, 1)$ instead.

  1. $(7, 4) = 1\mathbf{u} + 2\mathbf{v}$
    We found this recipe in Section 1.
  2. Coordinates in the new basis: $(1, 2)$
    Same point, different description. The numbers depend on which "rulers" you measure with.
Standard coordinates $(7, 4)$ = new-basis coordinates $(1, 2)$. Changing basis is just re-describing the same thing.
In real life

Directions in a city: "3 blocks east and 4 blocks north" uses east and north as a basis. In a city with diagonal avenues, a local might say "2 blocks up the avenue, then 1 block across": different basis, same destination. In ML, PCA (Module 5) finds a new basis for your data where the first direction captures the most variation, like describing people by "overall size" instead of separate height and weight.

A basis is a set of rulers. Change the rulers, and the numbers change, but the thing doesn't.

Rank: how much real information is in a matrix?

≈ 20 min

The rank of a matrix is the number of independent rows (which always equals the number of independent columns). It counts how many genuinely different pieces of information the matrix holds.

Worked example · rank of $\begin{bmatrix}1&2&3\\2&4&6\\1&0&1\end{bmatrix}$
  1. Row 2 $= 2 \times$ Row 1
    $(2, 4, 6) = 2(1, 2, 3)$. Row 2 is redundant.
  2. Row 2 − 2·Row 1 $= (0, 0, 0)$
    Elimination (Module 1) turns a redundant row into all zeros.
  3. Rows 1 and 3, $(1, 2, 3)$ and $(1, 0, 1)$, aren't multiples of each other
    So they're independent.
Rank = 2. Three rows, but only two pieces of real information.
In real life

Think of a movie-ratings table: millions of users by thousands of movies. People's tastes are driven by a handful of factors (likes action, likes comedy, likes older films…), so the table has low rank even though it's huge. Streaming services use this to fill in the blanks and predict ratings you haven't given yet.

Rank = how many questions you really asked, after removing repeats. 
import numpy as np
M = np.array([[1, 2, 3], [2, 4, 6], [1, 0, 1]])
print(np.linalg.matrix_rank(M))   # 2

Kernel: the inputs that disappear

≈ 20 min

The kernel (or null space) of a matrix $A$ is every input $\mathbf{x}$ with $A\mathbf{x} = \mathbf{0}$: changes to the input that the matrix can't see.

Worked example · kernel of $A = \begin{bmatrix}1&2\\2&4\end{bmatrix}$
  1. $x + 2y = 0, \quad 2x + 4y = 0$
    Write out $A\mathbf{x} = \mathbf{0}$. The second equation is just twice the first.
  2. $x = -2y$
    Only one real equation, so one variable stays free.
  3. $\mathbf{x} = t(-2, 1)$ for any number $t$
    Check: $1(-2) + 2(1) = 0$ ✓.
The kernel is a whole line of inputs, all sent to $(0, 0)$.

A neat fact ties this together, the rank–nullity theorem: rank + (dimension of the kernel) = number of columns. Here: rank 1 + kernel dimension 1 = 2 columns. Every dimension either survives (rank) or gets crushed (kernel).

In real life

A kitchen scale that only reports the total weight of flour plus sugar can't tell "add 1 cup flour, remove 1 cup sugar" from doing nothing: that swap is in its kernel. In regression, if your data has redundant columns, there's a kernel of parameter changes that leave every prediction unchanged, so the model can't decide between them. That's why the fitted coefficients jump around wildly on such data.

The kernel is the blind spot: changes the matrix can't see.

Key terms

Span
Every vector you can build as a linear combination of a given set.
Independent
No vector in the set can be built from the others.
Basis
An independent set that spans the whole space.
Dimension
The number of vectors in a basis.
Rank
The number of independent rows (or columns) of a matrix.
Kernel
All inputs that a matrix sends to the zero vector.
