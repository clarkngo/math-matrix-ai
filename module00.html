The Math Toolkit: Reading the Symbols

Most of the "hard" math in machine learning is algebra you already know, written in a compressed notation. This module translates every symbol you'll meet back into plain algebra.

📊 Beginner⏱ ~1 hour🧮 Needs: basic algebra
Overview Subscripts & Vectors Sums (Σ) Functions Slope → Derivative Symbol Decoder Course Map Review

Why start here

When you see something like $\boldsymbol\theta_{\text{MAP}} = \arg\max_{\boldsymbol\theta} \sum_n \log p(y_n \mid \boldsymbol\theta)$, it looks like a different language. It isn't. Every piece of it is something you have done in algebra class: plug numbers into a formula, add up a list, find where a curve is highest. The notation just packs a lot into a small space.

The rule for this whole course: whenever you see a new symbol, ask "what would this be with actual numbers?" Every module does that for you with worked examples.

By the end of this module you will be able to

  • Read subscripts like $x_1, x_2$ and vectors like $\mathbf{x} = (3, 4)$.
  • Expand a sum written with $\Sigma$ and compute it.
  • Use function notation $f(x)$ and evaluate a function at a point.
  • Explain a derivative as the slope of a curve at a point.
  • Recognize the Greek letters the course uses and what each usually means.

Subscripts and vectors: naming a list of numbers

≈ 10 min

In algebra you used separate letters: $x$, $y$, $z$. Once you have 100 variables you run out of letters, so math uses one letter with a small number underneath, called a subscript: $x_1, x_2, x_3, \dots$. The subscript is just a label, like a seat number. $x_2$ means "the second $x$", not "$x$ times 2".

A vector is an ordered list of numbers, written in bold: $\mathbf{x} = (x_1, x_2)$. You can read it two ways, and both are useful:

  • As data: a house with 3 bedrooms and 4 bathrooms is $\mathbf{x} = (3, 4)$.
  • As an arrow: start at the origin, go 3 right and 4 up.
You already know this

A point $(3, 4)$ on a graph is a vector. You've been using vectors since you first plotted points.

Worked example · adding and scaling vectors

Let $\mathbf{a} = (1, 2)$ and $\mathbf{b} = (3, 1)$.

  1. $\mathbf{a} + \mathbf{b} = (1+3,\; 2+1) = (4, 3)$
    Add matching positions. First with first, second with second.
  2. $2\mathbf{a} = (2\cdot1,\; 2\cdot2) = (2, 4)$
    Multiplying by a number (a scalar) multiplies every entry. As an arrow, it points the same way but is twice as long.
  3. $2\mathbf{a} + \mathbf{b} = (2+3,\; 4+1) = (5, 5)$
    Combine the two rules. This "scale then add" move is called a linear combination, and it is the single most important operation in this course.
In real life
  • Your location on a map app is a vector: (latitude, longitude) = (47.61, −122.33) for Seattle.
  • A color on your screen is a vector of red, green, blue amounts: orange is (255, 165, 0).
  • A recipe is a vector of amounts: (2 cups flour, 1 cup sugar). Doubling the recipe is $2 \times (2, 1) = (4, 2)$. Making one batch of cookies plus one batch of cake is adding the two recipe vectors.

Streaming apps store each song as a vector like (tempo, energy, danceability). Songs with similar vectors get recommended together.

A vector is a shopping list where the order of items is fixed.
Try it yourself (click to reveal the answer)
With $\mathbf{a} = (1, 2)$ and $\mathbf{b} = (3, 1)$, compute $3\mathbf{a} - \mathbf{b}$.
$3\mathbf{a} = (3, 6)$, then subtract $\mathbf{b}$: $(3-3,\; 6-1) = (0, 5)$.

Sums with Σ: "add these up"

≈ 10 min

The capital Greek letter sigma, $\Sigma$, means "add up". It's shorthand for a long addition:

$$\sum_{i=1}^{3} i^2 \quad\text{means}\quad \text{"let } i \text{ go } 1, 2, 3\text{; compute } i^2 \text{ each time; add the results."}$$
Worked example · expanding a sum
  1. $i = 1:\; 1^2 = 1$
    Start at the number under the $\Sigma$.
  2. $i = 2:\; 2^2 = 4$
    Go up by one.
  3. $i = 3:\; 3^2 = 9$
    Stop at the number on top of the $\Sigma$.
  4. $1 + 4 + 9 = 14$
    Add everything you got.
$\displaystyle\sum_{i=1}^{3} i^2 = 14$

In machine learning the thing being summed is usually one term per data point. If you have three data points with errors $e_1 = 2$, $e_2 = -1$, $e_3 = 3$, the total squared error is

$$\sum_{n=1}^{3} e_n^2 = 2^2 + (-1)^2 + 3^2 = 4 + 1 + 9 = 14.$$
You already know this

An average is a sum divided by a count: $\bar{x} = \frac{1}{N}\sum_{n=1}^{N} x_n$. The average of $2, 4, 9$ is $\frac{1}{3}(2+4+9) = 5$.

A related symbol, the capital Greek pi $\prod$, means "multiply these together" instead of adding. You'll see it in probability (Modules 7 and 10): $\prod_{i=1}^{3} i = 1\cdot2\cdot3 = 6$.

In real life

Every receipt is a $\Sigma$. If you buy 2 coffees at \$3, 1 sandwich at \$5, and 4 cookies at \$1, the total is

$$\sum_{i=1}^{3} \text{qty}_i \times \text{price}_i = 2(3) + 1(5) + 4(1) = 15 \text{ dollars}.$$

Your phone's weekly step count, your monthly budget, and a teacher's class average all work the same way.

$\Sigma$ is the "Total" line at the bottom of a receipt.
Try it yourself (click to reveal the answer)
Compute $\displaystyle\sum_{k=1}^{4} 2k$.
$2(1) + 2(2) + 2(3) + 2(4) = 2 + 4 + 6 + 8 = 20$.

Functions: a machine that takes an input

≈ 10 min

$f(x) = x^2 - 4x + 3$ is a rule: give it a number $x$, it gives back a number. Writing $f(5)$ means "replace every $x$ with 5".

Worked example · evaluating a function
  1. $f(5) = 5^2 - 4(5) + 3$
    Replace each $x$ with 5.
  2. $= 25 - 20 + 3 = 8$
    Order of operations: powers, then multiplication, then add and subtract.

In ML, a function often takes a whole vector as input. A model that predicts house price from bedrooms $x_1$ and bathrooms $x_2$ might be

$$f(\mathbf{x}) = 50 + 30x_1 + 20x_2, \qquad f(3, 4) = 50 + 90 + 80 = 220 \text{ (thousand dollars)}.$$

The numbers $50, 30, 20$ are the model's parameters. Training a model means finding good values for them. The course writes parameters as $\boldsymbol\theta$ (theta), so you'll see $f(\mathbf{x};\boldsymbol\theta)$: "a function of the input $\mathbf{x}$, using parameters $\boldsymbol\theta$".

In real life

A rideshare fare is a function with three parameters: a base fee, a price per mile, and a price per minute.

$$\text{fare}(\text{miles}, \text{minutes}) = 2.50 + 1.20 \times \text{miles} + 0.30 \times \text{minutes}$$

A 10-mile, 20-minute ride costs $2.50 + 12.00 + 6.00 = \$20.50$. If you only had a pile of old receipts and had to work out the 2.50, 1.20, and 0.30, that would be training a model.

A model is a function; training is figuring out its numbers from examples.
Try it yourself (click to reveal the answer)
Using the house-price model above, what does it predict for a 2-bedroom, 1-bathroom house?
$f(2, 1) = 50 + 30(2) + 20(1) = 50 + 60 + 20 = 130$ thousand dollars.

From slope to derivative: how fast is it changing?

≈ 15 min

You know the slope of a line: rise over run. Through the points $(1, 2)$ and $(3, 8)$ the slope is $\frac{8-2}{3-1} = 3$. Every step right, the line goes up 3.

A curve doesn't have one slope; it's steeper in some places than others. The derivative $f'(x)$ is the slope of the curve at one point. You find it by taking the slope between two points that are very close together.

Worked example · the slope of $f(x) = x^2$ at $x = 3$
  1. $f(3) = 9, \quad f(3.001) = 9.006001$
    Pick a second point a tiny distance (0.001) to the right.
  2. $\text{slope} \approx \dfrac{9.006001 - 9}{0.001} = 6.001$
    Rise over run, exactly like a line.
  3. $f'(x) = 2x \;\Rightarrow\; f'(3) = 6$
    The power rule (below) gives the exact answer. Our estimate of 6.001 was very close.

You don't need to compute tiny differences every time. A few rules cover almost everything in this course:

RuleIn wordsExample
$x^n \to n x^{n-1}$Power rule: bring the power down, subtract one from it$x^3 \to 3x^2$
$c \to 0$A constant doesn't change, so its slope is zero$7 \to 0$
$c\,g(x) \to c\,g'(x)$Constants in front just come along$5x^2 \to 10x$
$g + h \to g' + h'$Take the derivative of each piece separately$3x^2 + 2x + 1 \to 6x + 2$
Why this matters for ML

Training a model means making an error function as small as possible. The derivative tells you which way is downhill: if the slope is positive, decrease $x$; if it's negative, increase $x$. That idea, "step downhill using the slope", is gradient descent (Module 9).

In real life

Your car's speedometer shows a derivative: how fast your position is changing right now. If a car's distance in meters after $t$ seconds is $d(t) = 5t^2$, its speed is $d'(t) = 10t$, so at $t = 3$ seconds it's going 30 meters per second.

Your phone's battery estimate ("12% per hour") is also a rate of change: the derivative of battery level over time.

The derivative is the speedometer, not the odometer.
Try it yourself (click to reveal the answer)
Find the derivative of $f(x) = 4x^2 - 3x + 10$, then its slope at $x = 2$.
$f'(x) = 8x - 3$. At $x = 2$: $8(2) - 3 = 13$.

Worked example · min vs. arg min

For $f(x) = (x - 3)^2 + 1$:

  1. $(x-3)^2 \ge 0$, and it equals $0$ only when $x = 3$.
    A square is never negative.
  2. $\min_x f(x) = 0 + 1 = 1$
    The smallest output.
  3. $\arg\min_x f(x) = 3$
    The input that produces that smallest output. In ML we almost always want the arg min: the parameter values, not the error value.
In real life

Picking the cheapest phone plan: Plan A costs \$40, Plan B \$35, Plan C \$50. The min is \$35. The arg min is "Plan B", the thing you actually sign up for. Training a model is the same: we want the settings (arg min), not just the error score.

min is the price you pay; arg min is the plan you pick.

Key terms

Vector
An ordered list of numbers, also pictured as an arrow from the origin.
Scalar
A single number, used to stretch or shrink a vector.
Linear combination
Scale some vectors and add them: $a\mathbf{u} + b\mathbf{v}$.
Parameter
A number inside a model that training adjusts.
Derivative
The slope of a function at a single point.
arg min
The input value that makes a function smallest.
