Module 6 · Vector Calculus

Partial Differentiation & Vector Gradients

A derivative is the slope of a curve. A gradient is the slope of a landscape: it points straight uphill, and training a model means walking the other way.

📊 Intermediate⏱ ~2 hours🧮 Needs: Module 0 (derivatives), Module 1
Overview Partial Derivatives The Gradient Chain Rule Backpropagation Matrix Shortcuts Review

Lesson overview

A model's error depends on many parameters at once, sometimes billions. To improve the model, we need to know how the error changes when we nudge each parameter. That's a list of slopes, one per parameter, called the gradient. Every neural network is trained by computing gradients.

By the end of this module you will be able to

  • Compute partial derivatives of a function of two variables.
  • Build the gradient vector and explain why it points uphill.
  • Use the chain rule on a function inside a function.
  • Do one step of backpropagation and gradient descent by hand.
  • Use a matrix-calculus shortcut and check it by expanding.
You needThe power rule and slopes (Module 0); vectors.
This unlocksGradient descent (Module 9) and how neural networks learn.

Partial derivatives: change one thing at a time

≈ 20 min

For a function of two variables, like $f(x, y) = x^2y + 3y$, ask two separate questions: how fast does $f$ change if I nudge only $x$? And only $y$? Each answer is a partial derivative, written with a curly $\partial$.

The trick: treat the other variable as a constant number, then use the ordinary rules from Module 0.

Worked example · $f(x, y) = x^2 y + 3y$ at the point $(1, 2)$
  1. $\dfrac{\partial f}{\partial x} = 2x\cdot y + 0 = 2xy$
    Treat $y$ like a number such as 5: $x^2\cdot5$ becomes $2x\cdot5$. The $3y$ term has no $x$, so it's a constant and its slope is 0.
  2. $\dfrac{\partial f}{\partial y} = x^2 + 3$
    Now treat $x$ as the constant: $x^2 y$ is "(a number) times $y$", whose slope is that number, $x^2$. And $3y$ has slope 3.
  3. At $(1, 2)$: $\;\dfrac{\partial f}{\partial x} = 2(1)(2) = 4, \quad \dfrac{\partial f}{\partial y} = 1 + 3 = 4$
    Plug in the point.
In real life

A farmer's crop yield depends on water and fertilizer. "If I add a bit more water but keep fertilizer the same, how much more corn do I get?" is a partial derivative. Economists call this the marginal effect, and it's the basis of every "all else being equal" claim.

Partial derivative = turn one knob, freeze all the others.
Try it yourself (click to reveal the answer)
For $g(x, y) = 3x + xy^2$, find $\partial g/\partial x$ and $\partial g/\partial y$.
$\partial g/\partial x = 3 + y^2$ (treat $y^2$ as a constant multiplier of $x$). $\partial g/\partial y = 2xy$ (the $3x$ term has no $y$).

The gradient: the uphill arrow

≈ 20 min

Stack all the partial derivatives into a vector and you get the gradient, written $\nabla f$ ("grad f"):

$$\nabla f = \left(\frac{\partial f}{\partial x},\; \frac{\partial f}{\partial y}\right).$$

It's an arrow that points in the direction where $f$ increases fastest. Its length tells you how steep that is.

Worked example · the bowl $f(x, y) = x^2 + y^2$ at $(1, 2)$
  1. $\nabla f = (2x,\; 2y)$
    Each partial uses only the power rule.
  2. At $(1, 2)$: $\nabla f = (2, 4)$
    Points away from the bottom of the bowl at $(0, 0)$, which is uphill.
  3. Steepness $= \lVert(2, 4)\rVert = \sqrt{20} \approx 4.47$
    The uphill slope in that best direction.
  4. Downhill direction $= -\nabla f = (-2, -4)$
    Flip the arrow to head toward the minimum. This is the heart of gradient descent.
In real life

Stand on a hillside: the gradient is the direction of the steepest climb. Water runs the opposite way, straight down the gradient, which is why streams cross contour lines on a hiking map at right angles. Heat flows the same way, from hot to cold along the temperature gradient.

The gradient points uphill; water (and training) goes the opposite way.

The chain rule: rates multiply

≈ 20 min

When one function sits inside another, like $h(x) = (3x + 1)^2$, the slopes multiply: the outer slope (evaluated at the inner value) times the inner slope.

Worked example · $h(x) = (3x + 1)^2$ at $x = 1$
  1. Inner: $u = 3x + 1$, slope $\dfrac{du}{dx} = 3$
    Name the inside piece.
  2. Outer: $h = u^2$, slope $\dfrac{dh}{du} = 2u$
    Power rule on the outside, treating $u$ as the variable.
  3. $\dfrac{dh}{dx} = 2u \cdot 3 = 6(3x + 1)$
    Multiply the two slopes, then put $u$ back.
  4. At $x = 1$: $6(4) = 24$
    Numerical check: $\frac{h(1.001) - h(1)}{0.001} \approx 24.009$ ✓.
In real life

What does a road trip cost per hour? You drive 60 miles per hour, the car uses 1/30 gallon per mile, and gas is \$4 per gallon. The rates multiply along the chain:

$$60\,\tfrac{\text{miles}}{\text{hour}} \times \tfrac{1}{30}\,\tfrac{\text{gallons}}{\text{mile}} \times 4\,\tfrac{\text{dollars}}{\text{gallon}} = 8\,\tfrac{\text{dollars}}{\text{hour}}.$$

The units cancel exactly the way the $du$'s cancel in $\frac{dh}{du}\cdot\frac{du}{dx}$.

Chain rule = multiply the rates along the chain, like unit conversions.

Backpropagation: one learning step by hand

≈ 25 min

The simplest possible "model" predicts $\hat{y} = w\,x$ with one parameter $w$. Its error on one example is the squared loss $L = (wx - y)^2$. Backpropagation is just the chain rule applied to this, working backward from the loss to the parameter.

Worked example · input $x = 2$, true answer $y = 10$, current $w = 3$
  1. Forward: $\hat{y} = 3 \times 2 = 6$, error $= 6 - 10 = -4$, $L = (-4)^2 = 16$
    Make a prediction and measure how wrong it is.
  2. $\dfrac{\partial L}{\partial \hat{y}} = 2(\hat{y} - y) = 2(-4) = -8$
    Backward, step 1: how the loss responds to the prediction (outer slope).
  3. $\dfrac{\partial \hat{y}}{\partial w} = x = 2$
    Backward, step 2: how the prediction responds to the weight (inner slope).
  4. $\dfrac{\partial L}{\partial w} = -8 \times 2 = -16$
    Chain rule. Negative means increasing $w$ lowers the loss.
  5. Update with step size $0.1$: $\; w \leftarrow 3 - 0.1 \times (-16) = 4.6$
    Step against the gradient (downhill).
  6. New prediction $4.6 \times 2 = 9.2$, new loss $(9.2 - 10)^2 = 0.64$
    The loss fell from 16 to 0.64 in one step.
In real life

Adjusting a shower: too cold, so you turn the handle toward hot, more if it's very cold, less if it's nearly right. That's a gradient step: the size of the correction depends on how wrong you are. A neural network does this for billions of "handles" at once, using backpropagation to work out how much each one contributed to the error.

Forward to measure the error; backward to blame each parameter; then nudge.

Matrix shortcuts (and how to trust them)

≈ 15 min

ML papers use compact rules like $\nabla_{\mathbf{x}}(\mathbf{x}^\top A\mathbf{x}) = (A + A^\top)\mathbf{x}$. Don't memorize them blindly; you can always check one by expanding a small case.

Worked example · check the rule with $A = \begin{bmatrix}2&1\\1&3\end{bmatrix}$
  1. $\mathbf{x}^\top A\mathbf{x} = 2x_1^2 + 2x_1x_2 + 3x_2^2$
    Multiply out: $x_1(2x_1 + x_2) + x_2(x_1 + 3x_2)$.
  2. $\dfrac{\partial}{\partial x_1} = 4x_1 + 2x_2, \quad \dfrac{\partial}{\partial x_2} = 2x_1 + 6x_2$
    Ordinary partial derivatives.
  3. $(A + A^\top)\mathbf{x} = \begin{bmatrix}4&2\\2&6\end{bmatrix}\begin{bmatrix}x_1\\x_2\end{bmatrix} = \begin{bmatrix}4x_1 + 2x_2\\2x_1 + 6x_2\end{bmatrix}$ ✓
    The shortcut matches.
Shape check

A gradient always has the same shape as the thing you're differentiating with respect to. If $\mathbf{x}$ has 2 entries, $\nabla_{\mathbf{x}}f$ has 2 entries. Checking shapes catches most mistakes in ML math.

Key terms

Partial derivative
The slope with respect to one variable, holding the others fixed.
Gradient
The vector of all partial derivatives; points in the steepest uphill direction.
Chain rule
For nested functions, multiply the outer slope by the inner slope.
Loss
A number measuring how wrong a model is, such as squared error.
Backpropagation
Applying the chain rule backward from the loss to every parameter.
